
# Распознавание рукописных цифр MNIST

Я обучил полносвязные сети на PyTorch и сравнил, как глубина и функции
активации влияют на классификацию цифр. В эксперименте участвовали модели
с одним, двумя и тремя скрытыми слоями, а также двухслойные варианты
с собственной обучаемой активацией и без активаций.

Лучшая модель с двумя скрытыми слоями и обучаемым α показала **97,80%**
на валидации и **97,74%** на тесте. Архитектуру и чекпойнт я выбрал по
валидационной выборке. На тесте оценил только выбранный чекпойнт.

[Открыть ноутбук с графиками и выводами](main.ipynb)

## Как запустить

1. Установите зависимости командой `python -m pip install -r requirements.txt`.
2. Откройте `main.ipynb` в VS Code с расширением Jupyter.
3. Выберите Python, в который установили зависимости, и выполните все ячейки
   сверху вниз. Ноутбук скачает MNIST и обучит модели.

Настройки эксперимента — seed 42, Adam с `lr=0.001`, батч 256, 16 эпох.
